# Metalpol AI Complaint Automation

Rozwiązanie zadania rekrutacyjnego dla roli AI Automation Analyst. Repozytorium opisuje automatyzację obsługi reklamacji w firmie Metalpol: od analizy procesu AS-IS, przez projekt TO-BE, po mock MVP pokazujący pipeline reklamacyjny.

## Cel

Pokazać, jak kontrolowana automatyzacja AI może skrócić obsługę reklamacji, ograniczyć pracę manualną, poprawić spójność klasyfikacji i udostępnić metryki procesu bez przenoszenia finalnej decyzji reklamacyjnej na model AI.
