Demo procesu reklamacji

Metalpol Complaint Automation Control Center

Prosty pokaz procesu: mail z reklamacją trafia do intake, mock AI triage wyciąga dane, SAP ERP weryfikuje order i batch, Jira Cloud dostaje Complaint, a człowiek zatwierdza decyzję jakościową.

Problem biznesowy: opóźnione maile, ręczne przepisywanie danych, niespójna klasyfikacja, brak metryk oraz ręczne łączenie Microsoft 365 / Exchange, SAP ERP i Jira Cloud.

Demo działa na stanie in-memory. Restart API czyści reklamacje i KPI, a scenariusze można uruchamiać ponownie.

1 Wybierz scenariusz np. wada wizualna, brak orderu, prompt injection
2 Zobacz pipeline status, SAP, Jira, AI confidence i timeline
3 Zatwierdź review ConfirmDefect tworzy mock Jira Correction
